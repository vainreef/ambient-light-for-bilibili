# Ambient Light for Bilibili

为 B 站播放器投射实时流光氛围灯的 Manifest V3 浏览器扩展。当前版本：0.4.1。

## 渲染逻辑

- **正向模式**：完整视频帧按 `step = 1 + 2a` 同心放大，由外向内叠放。
- **镜像模式**：上下取完整宽度、左右取完整高度的边缘切片，向四边梯形展开；奇数圈反射、偶数圈正向承接。
- 每条边使用 **96 条轴对齐细条**，保留对角线闭合模型。
- 离屏绘制无模糊切片，再对整幅画面执行 **一次整体模糊**。中央绘制当前视频帧，避免用黑色矩形产生假黑边；固定扩边避免透明采样白圈。
- 播放器几何使用画布宿主的局部坐标。播放时每次绘制读取最新位置，暂停时监听窗口、布局属性、DOM 与祖先尺寸变化。
- 页面保持 B 站白色底，装饰层不扩大页面滚动范围。下方渐白固定在页面空间，滚动不会关闭顶部播放器背后的氛围光。

## 播放器内设置

悬停播放器控制栏的「氛围光设置」图标即可展开面板；移入面板继续调参，离开 280ms 后收起。也支持点击、Enter/空格和 Escape。面板锚定播放器内部，不固定在页面角落。

关闭氛围光只停止投射，设置入口始终保留；关闭状态刷新、渲染异常、播放器/控制栏重建后都可重新打开设置。

设置项：

| 设置 | 范围 | 默认 |
|---|---|---|
| 模式 | 正向 / 镜像 | 镜像 |
| 环带比例 | 5%～50% | 20% |
| 模糊强度 | 0～80px | 28px |
| 外展层数 | 1～12 层 | 4 层 |
| 下方显示距离 | 播放器底边之后 0～3000px | 600px |
| 渲染分辨率 | 50%～200% | 100% |

超过下方显示距离后，使用 **1200px 长的平滑过渡**逐渐合成到纯白色；白色渐变绘制在模糊之后。全屏播放不应用下方渐白。

暂停时单独调节模糊复用现有离屏内容。12 层的指数几何不用于分配画布高度；画布按显示区域限高，并对高分辨率缓冲设定尺寸/像素预算。

边缘暗影、右侧渐白已删除。设置保存在当前网站的本地存储中。

## 安装与更新

1. 打开 Chrome / Edge 的扩展管理页并启用开发者模式。
2. 选择「加载已解压的扩展程序」，选中项目根目录。
3. 修改后在扩展管理页点击该扩展的「重新加载」，然后刷新 B 站视频页面。

支持普通视频页、番剧播放页及独立播放器。
