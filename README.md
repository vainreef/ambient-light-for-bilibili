# Ambient Light for Bilibili

为哔哩哔哩（Bilibili）视频提供 WebGL 页面级氛围光的浏览器扩展。

---

## 效果说明

从视频画面最外一圈（默认每边 6%）开始，向画面外一圈一圈复制：

1. 第 1 圈 = 把整帧以画面中心为原点整体放大 `1 ÷ 0.88 ≈ 1.13636` 倍后露出的外圈；
2. 第 2 圈 = 再放大一次露出的外圈；以此类推，一直铺满页面；
3. 每一圈比上一圈更模糊（第 1 圈约 6px，最外圈约 76px，可在面板调节）；
4. 页面越往下颜色越淡，在视频简介后的下一段内容附近平滑淡回页面底色；
5. 视频本身保持原始清晰度，不参与模糊。

“把上一圈成品整体往外再复制一份”与“把原帧再放大一圈”在数学上等价（自相似），所以着色器直接对原帧做几何级数采样即可。

---

## 核心实现

- **WebGL 片元着色器**：环带索引 `floor(log(radius) / log(1 / 0.88))`，使用 `max(|qx|, |qy|)` 切比雪夫度量，保证副本始终是矩形的相似放大而非椭圆；先把整张"逐级往外扩大"的环场清晰渲染到离屏缓冲，再对整张图做 6 轮真高斯模糊（每轮横竖分离、半径翻倍，叠加后等于目标糊度），糊度随距离从 6px 连续增至 76px，因此圈与圈之间被一起糊开、没有硬接缝。
- **逐帧精准同步**：使用 `video.requestVideoFrameCallback` 对齐解码器渲染帧率，不空转。
- **全分辨率投射画布**：投影画布按设备像素比渲染（最高 2×，仅受 GPU 最大纹理尺寸限制），不做降采样。
- **动态黑边自适应裁剪**：检测带黑边的宽银幕视频，裁剪无效黑边后再投射，防止四周出现发黑死区。
- **整页环境投射**：颜色覆盖顶部导航、右侧推荐和播放器下方内容；播放器左置、滚动、网页全屏与系统全屏均可自适应；卡片等浅色表面自动透明化，让底层颜色透出。
- **小窗自动暂停**：检测到播放器进入小窗模式（`data-screen="mini"`）时自动隐藏投射层并停止绘制，滚回正常模式后自动恢复。
- **轻量设置面板**：快捷键 `Alt + A` 调出悬浮面板，可调开关、模糊强度与环带宽度。

## 安装与使用

### 开发者模式加载

1. 克隆或下载本项目至本地；
2. 打开 Chrome / Edge 等 Chromium 浏览器，进入扩展管理页 `chrome://extensions/`；
3. 打开右上角「开发者模式」；
4. 点击「加载已解压的扩展程序」，选择当前项目根目录即可。

### 快捷键

- 在 B 站视频播放页面按下 `Alt + A`，即可调出或收起氛围灯浮动控制面板。

### 浏览器视觉回归测试

仓库包含一页本地仿真播放器，使用合成视频帧检查递归复制、逐圈模糊、推荐栏覆盖、简介后渐退和快捷设置：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

随后在浏览器打开 `http://127.0.0.1:8765/tests/fixtures/bilibili-player.html`。页面会直接加载仓库中的当前渲染器与内容脚本。

单元测试：

```sh
npm test
```
