# 项目核心需求与强制规范 (Workspace Rule)

## 1. 核心需求概览
本项目为 `ambient-light-for-bilibili`，目标是为 Bilibili 播放器及独立演示系统构建高性能、零波浪纹、零卡顿、无黑块的流光氛围灯。

## 2. 模式与数学规则
1. **正向模式 (Forward Mode)**：
   - 步长 $\text{step} = 1 + 2a$（$a \in [0.05, 1.00]$，最大可达 3.0）。
   - 由外向内层层同心缩放放大（$S_k = \text{step}^k$），横向覆盖视窗。
2. **镜像模式 (Mirror Mode)**：
   - **四边切片尺寸**：顶部 $W \times aH$、底部 $W \times aH$、左侧 $aW \times H$（**必须完整高度**）、右侧 $aW \times H$（**必须完整高度**）。
   - **梯形对角拉伸**：沿画幅对角线（$\theta = \arctan(H/W)$）放射拉伸，四角严密闭合。
   - **Ping-Pong 周期反射**：第 1 圈翻转镜像、第 2 圈不翻转（正向承接）、第 3 圈翻转镜像……判定式：`isMirrored = (k % 2) === 1`。

## 3. 渲染管线与性能铁律
1. **零波浪纹**：必须采用 1D 平行细条映射（Top/Bottom 沿 Y 轴水平细分 96 条，Left/Right 沿 X 轴垂直细分 96 条），严禁使用 2D 网格三角剖分。
2. **零卡顿（双阶离屏模糊）**：
   - 离屏缓冲 `ambientBufferCanvas` 以 `filter = 'none'` 绘制 1536 个几何切片（耗时 0.3ms，仅在几何变动时重绘）。
   - 主画布仅对烘焙好的离屏画面执行 1 次全局模糊（耗时 0.2ms）。
   - 调节模糊滑块时完全跳过切片重算，全程 60fps / 120fps 满帧。
3. **模糊白圈防护（现行标准）**：
   - 删除边缘暗影、右侧渐白控件和绘制逻辑，覆盖此前相关规范。
   - 离屏白色页面底上使用当前视频帧填实播放器中央，严禁中央黑色/深炭灰矩形；固定 320px 扩边；暂停时调模糊复用缓存，播放中新帧更新采样内容。
   - 实际插件与演示共用上述正向/镜像几何标准，插件面板保留播放器内设置入口，并提供模式、环带、模糊、层数、开关、分辨率。
4. **零抖动与零黑块**：
   - 画布统一在 `inset: 0` 视窗对齐下渲染，严禁使用引发透明采样暗边的 DOM 级 CSS 模糊。
   - 统一使用 `ctx.setTransform(scale, 0, 0, scale, 0, 0)` 锁定逻辑坐标。
5. **单一文档滚动**：B 站布局验证页仅由文档根节点承担纵向滚动，`body` 不建立独立滚动容器。氛围画布位于覆盖正文的绝对定位 `overflow: clip` 装饰层内，其外扩高度不扩大文档滚动范围；滚动时继续常驻播放器背后，不加入淡出逻辑。

## 4. UI 约束
- 必须严格保留项目原版 UI（暗黑背景 `#0b0e14`、顶部诊断卡、底部 HUD 控制坞、对角辅助线），严禁擅自修改或重写 UI。
- 上述暗黑背景仅指独立几何演示。实际 B 站插件保持白色页面底与浅色配色；投射之外的缓冲底为白色，播放器中央使用当前视频帧填实。用户自行进行浏览器检查。

## 5. 需求同步要求
- 每次用户提出新需求或变更时，必须立即同步更新本文件与 `AGENTS.md` 及 `.agents/requirements_log.md`。

## 6. 最新增补（2026-10-01）
- **默认参数配置标准**：模式默认正向模式 (`forward`)、渲染分辨率 100%、模糊强度 18px、环带比例 100%（$a = 1.00$）、外展层数 12层、下方显示距离 200px、过渡延迟 120ms、背景暗度 0%、视频阴影 50px。
- 环带比例 $a$ 扩展至 5%~100%（$a \in [0.05, 1.00]$），单圈几何步长 $\text{step} = 1 + 2a$ 最大为 3.0；外展层数为 1~12；下方显示距离 0~500px、步长10px、默认200px，自视频垂直几何中心起算，后接 600px 极缓渐白过渡（64 阶五次 Smootherstep 多项式插值），并在全局模糊后合成，使光晕在到达评论输入框附近时恰好完全过渡至 100% 纯白网页底色。
- 画面转变过渡延迟（`inertia`，0~400ms，默认 120ms），采用时域指数平滑插值（$\alpha = 1 - e^{-\Delta t / \tau}$），支持 60Hz/120Hz 柔和换景且在尺寸重设/Seek时瞬时刷新无拖影。
- 适配器严格锁定主播放器视窗容器，消除页面加载期间滚动产生的画布视口相对偏差，确保氛围光中心永远精准居中于视频。
- 原点以投射层真实位置为准，播放每帧校准、暂停监听布局位置变化；即使尺寸未变也须响应位移。
- 渐白是文档空间固定区域，不是滚动触发淡出。投射缓冲高度受显示区域限制，12层不导致指数增长的画布分配。最小设定（0px）时光晕自视频中心启动渐变并在评论区附近极度平缓消融融白，彻底杜绝向下过度溢出或突兀分界。

## 7. 设置入口可靠性
- 开关只控制氛围渲染与页面效果，设置入口和控件监听始终独立保留。
- 面板位于当前播放器内的弹出层，悬停展开、离开延时收起，按钮/面板间移动不中断调参；点击、键盘与触屏仍可操作。
- 禁止入口使用通用is-disabled/disabled类或属性；渲染器失败和初始几何未准备好不销毁UI。
- 观察document范围，控制栏/播放器替换后验证宿主并迁移同一入口与面板；不要仅凭isConnected判断挂载正确。
- 先创建设置UI，再发现播放器、按需初始化渲染器。渲染故障仅停止投射并独立重试，关闭状态刷新不初始化渲染器；BFCache及后台恢复继续校验入口。
- 当前控制栏以真实布局矩形筛选，跳过仍连接但已隐藏的旧控制栏；按钮进入后延时 280ms 展开面板，移除浮动提示文字（直接仅展开面板），离开预留 280ms 收起延迟，拖动滑块期间保持展开。

## 8. 架构清理与工程规范（2026-10-01）

- 独立几何演示统一使用 `standalone.html`，B 站布局验证统一使用 `recursive-copies-page.html`，实际插件源码测试统一使用 `tests/fixtures/bilibili-player.html`。
- 确保 `npm run check` 与 `npm test`（含 9 组核心自动化测试）持续保持 100% 绿色通过。

## 9. 滤镜、视频阴影与面板正上方弹出规范（2026-10-01）
- **背景暗度滤镜 (`dimming`)**：调节范围 0%~100%（步长 5%，默认 0%），通过全屏模糊管线实时调整氛围光背景亮度，下边缘保持平滑纯白消融。
- **视频播放器阴影 (`shadow`)**：调节范围 0~100px（步长 2px，默认 50px），通过 CSS 变量 `--bili-ambient-shadow` 动态无开销投射播放器外发光/投影。
- **面板正上方居中定位**：计算按钮水平中心 `buttonCenterX = (button.left + button.width / 2 - host.left)`，将面板位置设为 `left = buttonCenterX - panelWidth / 2`，确保悬停或点击时面板在按钮正上方优雅居中弹出，杜绝向左上偏移。

## 10. 提示文字清理、6 阶平滑扩散 Drop-Shadow 与移除分辨率设置（2026-10-01）
- **移除冗余提示文本**：删除所有设置面板与演示页面中的“控制下方氛围灯延伸距离，从视频中心起超长渐变平滑过渡至纯白。”提示文字。
- **6 阶多重指数扩散 Drop-Shadow**：
  - 仅保留单一核心参数“视频阴影 (`shadow`: 0~100px，步长 2px，默认 50px)”，移除所有多余控件。
  - 根除 CSS 嵌套多重阴影渲染（仅最外层播放器容器渲染一次，内部子元素 `box-shadow: none !important`）。
  - 采用 6 阶多重指数级扩散衰减算法（`computeDropShadow`）：`0 0 r px rgba(0,0,0,alpha)`，最内层为微透半透明（非实心黑），随外展距离指数级增大模糊半径并递减透明度，完全杜绝实心黑块，呈现真正的柔和自然 drop-shadow。
- **移除渲染分辨率设置**：内部默认固定锁定 100% 满画质无损渲染（`resolution: 1.0`），设置面板完全移除分辨率调节项，不允许用户随意降质。

## 11. 开关按钮移至面板最底部（2026-10-01）
- **移除顶部开启状态按钮**：移除面板顶部标题栏中的「已开启」按钮，顶部仅保留简洁标题与关闭叉号。
- **底部全宽切换按钮**：在面板最下方（所有滑块之后）放置全宽切换按钮：
  - 氛围灯开启时（`enabled: true`），按钮显示为「关闭氛围灯」（次级暗底通透风格）。
  - 氛围灯关闭时（`enabled: false`），按钮显示为「开启氛围灯」（高亮 B 站蓝强调底色），视觉焦点更加清晰、布局操作更加舒适。

## 12. 非侵入性样式原则与原生配色保护（2026-10-01）
- **严禁覆盖 B 站原生文字颜色与组件样式**：
  - 插件核心职责是且仅是在播放器背后投射氛围光，严禁对 B 站页面元素（如 `.up-name`、`h1`、`.video-title`、`.video-data`、`.pubdate-ip`、标签、推荐卡片等）施加任何 `color: ... !important` 或自定义边框。
  - 必须完整保留 B 站原生的大会员 UP 主粉色（`style="color:#FB7299;"` / `.vip`）、大 VIP 红色/金色以及默认链接颜色。

## 13. 彻底阻止中央视频模糊向外漫溢（2026-10-01）
- **严禁在离屏缓冲中盖印 1x 未缩放视频帧**：
  - 在正向模式下，由具有 $(1+2a)$ 几何放大的第 1 圈外展环带直接覆盖中央区域，杜绝 1x 原始视频未放大的锐利边界与内容在全屏模糊时向外产生双重溢出。
  - 在镜像模式下，使用 4 条边边缘切片（`tex.*Normal`）向内缝合边缘接缝，杜绝视频深层中央内容跨边界越界扩散，使高斯模糊仅对纯净的外展氛围光起效。

## 14. 弹幕发送栏与发送按钮高亮规范（2026-10-01）
- 弹幕发送栏容器 `.bpx-player-sending-bar` 背景设为透明，输入框采用半透明毛玻璃边框。
- 输入框未输入文字（显示 placeholder）时保持通透，一旦输入文字（`:not(:placeholder-shown)`），采用 `field-sizing: content` 动态贴合已输入文字长度显示纯白背景（`#ffffff`，搭配深色字体 `#18191c`），输入多少字就纯白高亮多少字，外层输入框容器其余部分依然保持透明。
- 弹幕礼仪提示 `.bpx-player-dm-hint` 配置 `margin-left: auto !important; flex-shrink: 0 !important;`，确保在输入框自适应缩减时始终稳稳顶在输入栏的最右侧。
- 弹幕列表折叠头 `.bui-collapse-header`、`.bui-collapse-wrap`、`.bpx-player-filter` 背景设为透明，消除阻挡氛围光的实心底色。
- 弹幕列表中选中/当前激活项 `.bui-long-list-item-selected` 内部文字高亮为 B 站原生蓝（`color: #00aeec !important;`）并搭配柔和微蓝背景（`rgba(0, 174, 236, 0.16)`）。
- 视频简介整体容器 `.video-desc-container` / `#v_desc` 配置为 8px 圆角与 10px 模糊的高透白色磨砂卡片（更高透明度 `rgba(255, 255, 255, 0.22)`），将简介内容与「展开更多」整体包含在内，透出底层氛围光，内部子元素背景设为透明无嵌套边框。
- 发送按钮 `.bpx-player-dm-btn-send` 始终保持高亮 B 站蓝（`#00aeec`）与纯白文字，杜绝在禁用或默认状态下变灰变暗。
